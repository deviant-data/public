What this shows

Where data enters, how much text is usable, source share, recency, and up to 365 days of source-day flow.

Method

Source atlas is built from source statistics and the 365-day source_day index. The drift panel compares queued, inserted, duplicate, failed, and text-bearing rows so provenance shifts are visible before downstream interpretation.

How to read it

Compare source share, text coverage, failed/duplicate activity, and recency before trusting downstream patterns.

Why this matters

Rules, clusters, and entity maps inherit the shape of the sources. A source shift can look like a topic shift if provenance is hidden.

Long horizon value

A source atlas keeps future replay explainable because every view can point back to provenance and source reliability.
