What this shows

The intake and operating path: queue health, source velocity, downstream drift, recent runs, and anomaly timing in one place.

Method

Ingestion combines intake mechanics and system monitoring from one compact monitor payload and hourly operations index. Queue series, waterfall stages, source velocity, drift, rule, bridge, run, and anomaly views share that read model.

How to read it

First check whether queued items are draining, then compare API arrival with inserted items. A healthy page shows temporary deviation returning toward zero without requiring manual intervention.

Why this matters

Ingestion is the first point where source pressure can distort the rest of the system. One page keeps the backlog and its downstream effects visible without a second operations dashboard.

Long horizon value

Over years, this view becomes the evidence trail for peak-hour pressure, source bursts, and the moments where collection behavior changed.
