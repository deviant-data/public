What this shows

The intake layer: queue health, ingestion waterfall, source velocity, and anomaly timing in one place.

Method

The ingestion view separates intake mechanics from system monitoring. Queue series, waterfall stages, source velocity, and anomaly marks are built from the same compact monitor payload and hourly operations index.

How to read it

First check whether queued items are draining, then compare API arrival with inserted items. A healthy page shows temporary deviation returning toward zero without requiring manual intervention.

Why this matters

Ingestion is the first point where source pressure can distort the rest of the dashboard. Keeping it separate makes operational backlog visible before it becomes a knowledge problem.

Long horizon value

Over years, this view becomes the evidence trail for peak-hour pressure, source bursts, and the moments where collection behavior changed.
