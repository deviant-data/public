What this shows

Named entities as hubs, communities, and bridges, capped so the shape remains legible.

Method

The entity network is a bounded graph layout. Nodes are ranked entities, edges are extracted relationships, and bridge edges are highlighted because they connect otherwise separate components.

How to read it

Look for stable bridges and named hubs; omitted nodes are lower-priority detail.

Why this matters

A readable entity network shows which names connect otherwise separate areas of the corpus.

Long horizon value

A decade graph should become an entity lineage map rather than a dense node cloud.
