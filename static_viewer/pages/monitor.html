What this shows

Intake, queue drain, source velocity, mining state, rule maturity, and bridge movement.

Method

Operations health uses compact 30-minute buckets from the production queue, runs, mining outputs, and entity bridge tables. It is a status page for whether the system is behaving, not the place to inspect every ingestion detail.

How to read it

A rising queue is acceptable only when projected drain stays inside the target window.

Why this matters

Operations health determines whether visual meaning is trustworthy. Backlogs and failed jobs can distort every downstream view.

Long horizon value

This becomes the operations memory for bottlenecks, breakpoints, and production drift.
