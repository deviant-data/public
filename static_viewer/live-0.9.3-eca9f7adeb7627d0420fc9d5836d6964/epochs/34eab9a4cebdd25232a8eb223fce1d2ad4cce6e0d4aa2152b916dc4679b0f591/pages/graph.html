About this view

What this shows

Named entities as hubs, communities, and bridges, capped so the shape remains legible.

Method

The entity network uses a bounded, explicitly counted witness projection. Node ranks, components and bridges apply only to selected witnesses; omitted evidence may alter all three. Extracted relationships do not establish causality.

How to read it

Hubs, components and bridges describe the selected projection. Omitted witnesses can change its structure; they are not evidence of absence.

Why this matters

A readable entity network shows which names connect otherwise separate areas of the corpus.

Long horizon value

A decade graph should become an entity lineage map rather than a dense node cloud.
