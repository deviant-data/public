What this shows

Directed relationships counted across distinct logical evidence windows, with source revisions and concept meaning preserved.

Method

One active contribution per hypothesis and logical window is counted. Corrections replace earlier contributions. Observed rates describe this evidence; no Bayesian posterior, independent-trial claim, or validated maturity is implied.

How to read it

Supported / eligible windows gives the observed recurrence rate. Windows can be correlated; counts do not establish independence or predictive usefulness.

Why this matters

A source correction replaces its contribution. Replaying the same window does not create another trial.

Long horizon value

Sealed epochs retain the evidence and concept versions needed to revisit a claim. Future held-out evaluation remains a separate gate.
