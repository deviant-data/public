About this view

What this shows

The compact system readout: corpus counts, drift, central entities, recent jobs, and the long-horizon view modules that explain how the corpus is changing.

Method

A cached overview payload is rebuilt after collection and maintenance. The page reads bounded counts, top drift rows, top central entities, and recent run status so the entry point does not scan every long-horizon table at request time.

How to read it

Start here, then move into the module that answers the next question: source change, entity movement, rule maturity, storage pressure, or anomaly timing.

Why this matters

A stable overview prevents the dashboard from becoming a set of disconnected charts. It should tell what changed before asking anyone to decode details.

Long horizon value

Over years, the overview becomes a daily memory of what emerged, persisted, bridged fields, or stalled.
