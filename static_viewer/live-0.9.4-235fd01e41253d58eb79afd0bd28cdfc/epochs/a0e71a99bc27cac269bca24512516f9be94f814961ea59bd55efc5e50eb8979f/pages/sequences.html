About this view

What this shows

Directional recurrence: whether a later outcome appears after an eligible antecedent event within the stated observation horizon.

Method

The active directional-event method uses the epoch's pinned concept meaning and horizon. Source corrections replace earlier contributions; rereading an event does not create another trial. Eligible-event coverage and omitted evidence remain separate from observed support.

How to read it

The horizon is shown in seconds for each claim. Eligible events have completed that horizon; supported events are those with the later outcome inside it. Their ratio is the observed event rate.

Why this matters

An unfinished horizon is pending evidence, not a negative outcome. Open Exact outcomes to inspect the sealed event windows and their source revisions.

Long horizon value

Historical epochs preserve which events and source revisions supported each claim. Temporal order and correlation do not establish independence, causality, or future predictive performance.
