# Static Viewer v4

Static Viewer v4 is a static public surface for Streamlearn state.

It can serve either:

- static pages generated by the server-side publisher
- a fallback data renderer from:

```text
state/latest.json
```

Static Viewer v4 does not select endpoints and does not expose the private Streamlearn service.

## Files

- `index.html` / `render.html` - static entry points
- `render.js` - static page loader with state fallback
- `render.css` - Streamlearn-compatible dashboard styling
- `schema.js` - minimal state validation
- `sw.js` - latest-state cache

## Publish Shape

```text
static_viewer/
  index.html
  render.html
  render.css
  render.js
  schema.js
  sw.js
  pages/
    overview.html
    ...
  static/
    sl.js
  state/
    latest.json
```
