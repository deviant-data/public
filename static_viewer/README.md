# Static Viewer v5

Static Viewer v5 is a static public surface for Streamlearn state.

It can serve either:

- static pages generated by the server-side publisher
- a fallback data renderer from:

```text
state/latest.json
```

Static Viewer v5 does not select endpoints and does not expose the private Streamlearn service.

V5 adds manifest-controlled state mode. If `pages/manifest.json` contains
`"stateOnly": true`, `"preferState": true`, or `"viewerMode": "state"`, the
root shell renders `state/latest.json` instead of redirecting to generated
pages. Generated pages also hand off to the root state renderer when the
manifest requests state mode.

## Files

- `index.html` / `render.html` - static entry points
- `render.js` - static page loader with state fallback
- `render.css` - Streamlearn-compatible dashboard styling
- `schema.js` - minimal state validation
- `sw.js` - latest-state cache

## Publish Shape

```text
static_viewer/
  index.html
  render.html
  render.css
  render.js
  schema.js
  sw.js
  pages/
    overview.html
    ...
  static/
    sl.js
  state/
    latest.json
```
